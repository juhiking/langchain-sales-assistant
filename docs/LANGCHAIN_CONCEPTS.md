# LangChain Concepts Used in This Project

## 1. Prompt Templates
Define reusable prompt structures with variables.

## 2. LLM Chains
Connect multiple LLM calls together for complex workflows.

## 3. Output Parsing
Structure unstructured LLM responses into JSON or other formats.

## 4. Memory
Maintain conversation context across multiple interactions.

## 5. Tools & Functions
Enable LLMs to call functions and take actions.

## 6. Agents
Let LLMs decide which tools to use for a task.
